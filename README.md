# 🔒 Anonymous E2EE Chat

Легковесный, полностью анонимный чат со **сквозным шифрованием (E2EE)**, работающий исключительно на стороне клиента (в браузере). Не требует сервера, базы данных или регистрации.

## 🚀 Особенности

- **Настоящий E2EE**: Сообщения шифруются до того, как попадут в хранилище браузера.
- **Криптография веб-стандартов**: Используется нативный `Web Crypto API`.
  - **SHA-256**: Для хеширования сида и генерации уникального анонимного ID пользователя.
  - **AES-GCM (256-bit)**: Для симметричного шифрования и расшифровки сообщений с использованием случайного вектора инициализации (IV).
- **Serverless**: Для демонстрации и локального использования применяется `localStorage` (сообщения синхронизируются между вкладками одного браузера).
- **Безопасность**: Встроенная защита от XSS-атак при рендеринге сообщений.
- **UI/UX**: Современный темный интерфейс, адаптивный дизайн, кнопка принудительного обновления и автопрокрутка.

## ⚙️ Как это работает (Криптография)

1. Пользователь вводит **Имя** и **Секретный сид**.
2. **Генерация ID**: `SHA-256(Имя + Сид)` → создается уникальный анонимный идентификатор пользователя.
3. **Деривация ключа**: `SHA-256(Сид)` → преобразуется в 256-битный сырой ключ (`Raw Key`).
4. **Импорт ключа**: Ключ импортируется в `crypto.subtle` как неэкспортируемый ключ для алгоритма `AES-GCM`.
5. **Отправка**: Текст сообщения шифруется с новым случайным `IV`. В хранилище сохраняются только `{ iv, ciphertext }`.
6. **Получение**: При чтении хранилища браузер расшифровывает сообщение тем же ключом. Без правильного сида текст нечитаем.

## 🛠️ Технологии

- HTML5, CSS3 (CSS Variables, Flexbox)
- Vanilla JavaScript (ES6+)
- Web Crypto API (`crypto.subtle`)

## 🚀 Как запустить

### Способ 1: Простой запуск (для тестирования в одном браузере)
1. Скачайте и извлеките.
2. Откройте файл `Anonymous.html` в браузере.
3. Откройте **вторую вкладку** с тем же файлом.
4. Введите одинаковый **Сид** и разные **Имена** в разных вкладках.
5. Общайтесь! Сообщения будут автоматически появляться в соседней вкладке.
